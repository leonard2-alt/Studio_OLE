# Studio OLE — Games & Animations

Studio OLE is a responsive static website showcasing a creator’s ideas for games and animated stories. Its dark, space-inspired design brings each project into its own illustrated card and gives visitors a simple way to explore the growing creative universe.

## Featured projects

### Games

- **Guardians of Mali** — an adventure about guardians protecting their home.
- **Toad Squad** — a bright team adventure starring a fearless crew of toads.
- **Demon Slayer** — a fantasy action concept set against supernatural danger.

### Animations

- **Bait** — a mysterious short story.
- **Fuck am Dead** — a darkly playful animated story.
- **Wiru and the Lost Princess** — a fairy-tale adventure following Wiru on a search for a lost princess.

## Features

- Responsive layout for desktop and mobile screens
- CSS-only illustrated artwork and subtle motion
- Clear project sections with game and animation link placeholders
- Semantic HTML, keyboard focus styles, and reduced-motion support
- No JavaScript or build tools required

## Project files

- `index.html` — page content and structure
- `styles.css` — responsive styling and illustrated visuals

Project access links are placeholders until playable builds and videos are available. The contact link is also a placeholder.
